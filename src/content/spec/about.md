一名普通本科生，目前主要关注 **AI 应用开发、Agent、前沿 LLM、Harness 与内容生产**。

如果只用“AI 爱好者”来形容我，其实有点太宽泛。我对 AI 的兴趣已经逐渐从“模型好不好用”，深入到了模型为什么会表现成这样、能力边界在哪里，以及未来的人机协作方式会发生什么变化。

## 从模型能力，到真正能工作的系统

在大模型领域，我长期关注 **Foundation Model、LLM Architecture、Reasoning Model、Pre-training / Post-training、Reinforcement Learning、Context Engineering、Inference Scaling、Model Alignment 与 AI Safety**。

相比单纯看 Benchmark 排名，我更喜欢研究不同模型在真实任务中的能力差异，例如 Coding、长程推理、工具调用、复杂任务规划、上下文保持以及 Agentic Task Execution。

我也非常关注 **Agentic AI**，包括 Agent Harness、Tool Use、Skill System、Prompt Engineering、Context Engineering、Memory、Checkpoint、Evidence Ledger、Error Propagation、Self-Recovery，以及智能体在长时间运行中的可靠性与可恢复性。

相比一次性完成一个 Prompt，我更感兴趣的是：怎样让模型成为一个能够持续工作、调用工具、处理异常、积累上下文并完成复杂目标的“系统”。

## Coding Agent 与本地推理

Coding Agent 我也爱玩。我会关注 SWE Benchmark、真实代码仓库修复、Agent Harness 设计、模型 Coding 能力测试，以及不同模型在 Repository-level Software Engineering 上的表现。

对我来说，模型测试并不是简单地“问几道题”，而是更接近 **Evaluation Engineering**——通过真实任务、失败案例和边界条件判断模型到底具备什么能力。

我也很喜欢折腾本地模型和推理系统，包括 **GGUF、Model Quantization、VRAM / RAM Offloading、llama.cpp、Ollama、本地推理 Runtime、推理吞吐与显存效率**。我会去比较不同参数规模、不同量化精度，以及模型能力损失和本地硬件资源之间的 trade-off。

## 技术如何进入商业世界

除了底层模型，我对 AI 如何真正进入商业世界同样感兴趣。目前我比较关注 **AI Visibility / LLM Search Optimization**。

我也在尝试构建自己的 **Business Intelligence / Commercial Intelligence Workflow**：通过 OSINT、多源信息采集、Trend Detection、Signal Filtering、AI Scoring、Research Pipeline，把新闻、行业数据、社交媒体、GitHub、RSS 等大量碎片信息转化成真正值得研究的议题。

我长期关注 **AI Infrastructure、算力、GPU、光通信、芯片、模型 Scaling、推理成本和 AI 产业链**。我尤其喜欢观察技术进步怎样一步一步传导到产业，再从产业传导到资本市场和普通人的生活。（SB大A）
