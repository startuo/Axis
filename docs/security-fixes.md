# 安全修复记录

已修复源码审查的 1 项高危及 2 项中危。原始报告保留为审查时点记录。本次未读取、更改真实 `.env`，未连接生产数据库或部署。

## 1. JWT 默认密钥（高危）

`apps/api/src/config/env.validation.ts` 在所有环境要求显式 `JWT_SECRET`；拒绝缺失、空白、少于 32 UTF-8 字节及常见占位密钥。不再回退公开固定字符串。长度校验不能证明随机性，部署时需配置随机生成的密钥。此前若使用默认密钥，应在部署配置中更换；本次没有执行凭据轮换。

## 2. 认证限流（中危）

`apps/api/src/auth/auth-rate-limit.guard.ts` 在注册、登录进入业务服务及 Argon2 前使用 Redis Lua 原子校验、递增及设置 TTL。账户和 IP 以 SHA-256 摘要作为键，共享 Redis 的多个实例共享配额。

- 登录：每 IP 30 次/15 分钟，每规范化账户 10 次/15 分钟。
- 注册：每 IP 5 次/小时，每邮箱 3 次/小时，全站 100 次尝试/小时（保守创建上限，失败也计入）。
- 超限返回 429；Redis 出错返回 503，不放行认证。Redis 离线队列关闭，避免断线请求积压。
- 使用 Express `req.ip`，当前保持默认不信任代理；忽略客户端伪造转发头。反向代理部署时用户可能共享代理 IP 配额，需依据真实代理拓扑另行精确配置信任，不能设为无条件信任。

## 3. 匿名统计滥用（中危）

`dashboard.gateway.ts` 在握手验证 visitorId 类型、字符及 128 字符长度，绑定后心跳不能更换身份；每连接至少间隔 5 秒且最多一个写入在途。无效输入、未初始化连接及 Redis 异常不执行新成员写入。

`dashboard.service.ts` 通过 Lua 原子执行容量和预算：在线集合最多 10,000 个成员、每分钟最多 1,200 次更新；文章统计每分钟最多 600 次写入、每日 UV 最多 100,000 个成员、热门文章最多 10,000 个成员，保留 7 天。在线 TTL 限定 10–300 秒。预算耗尽暂停统计写入，不影响文章响应。定时快照至少间隔 1 秒且禁止并发生成，访客事件不再每次触发数据库快照。

HTTP UV 使用可信来源地址的 SHA-256 摘要，不使用任意 visitorId 或 X-Forwarded-For；同一出口下多个访客会合并。因此统计是受限的近似指标，不是精确人数或计费依据。Redis 统计异常不阻断文章阅读。
